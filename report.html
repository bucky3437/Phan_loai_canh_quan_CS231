📊II. MÔ TẢ BÀI TOÁN 15/15 ĐIỂM

2.1 Tổng quan

Phân loại ảnh cảnh thành 6 loại khác nhau sử dụng MobileNetV2 + Transfer Learning.

2.2 Input

Thuộc tính Chi tiết
Dạng dữ liệu Hình ảnh JPG/PNG
Kích thước input 224 × 224 pixels (3 channels - RGB)
Tiền xử lý Chuẩn hóa ImageNet: x = (x - mean) / std

2.3 Output

6 lớp phân loại:

Lớp Ký hiệu Ví dụ
Buildings Tòa nhà Kiến trúc đô thị, cao ốc
Forest Rừng Cây xanh, khu rừng
Glacier Sông băng Tuyết, băng
Mountain Núi Núi, đồi cao
Sea Biển Đại dương, bãi biển
Street Phố Đường phố, con phố

2.4 Kiến trúc mô hình

Input (224×224×3) ↓ MobileNetV2 (Frozen - Transfer Learning) ↓ GlobalAveragePooling2D (1280 → 1) ↓ Dropout (0.3) - Ngăn overfitting ↓ Dense(6) + Softmax ↓ Output (6 classes)

3.2 Mô tả độ đo đánh giá 5/5 ĐIỂM

3.2.1 Accuracy (Độ chính xác)

Công thức: Accuracy = (Số dự đoán đúng) / (Tổng số mẫu)
Ý nghĩa: Tỷ lệ % phân loại chính xác

3.2.2 Loss (Categorical Crossentropy)

Công thức: Loss = -Σ(y × log(ŷ))
Ý nghĩa: Đo sự khác biệt giữa dự đoán và thực tế (càng thấp càng tốt)

3.2.3 Validation Metrics

Đánh giá trên tập validation để phát hiện overfitting
